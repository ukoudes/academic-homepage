# Academic homepage

A responsive, static academic website with separate pages for research, publications, education, activities, and contact information. Personal details are placeholders to be replaced.

## Edit

Edit the HTML pages and `style.css` directly. The navigation and profile sidebar appear on every page. Replace the profile placeholder with your own photograph and add your real information and links.

## Preview

Run `python3 -m http.server 8000` from the repository directory, then visit http://localhost:8000.

## Publish with GitHub Pages

In the repository settings, select **Pages**, choose **Deploy from a branch**, and select the `main` branch and `/ (root)` folder. GitHub will provide the website address when deployment is complete.
